A combined **multi-parametric ultrafast ultrasound and photoacoustic imaging** platform for assessing cerebral hemodynamic and oxygen saturation changes in rodent brains.

Key contributions:

- Contributed ultrasound localization imaging methods, code development, and data analysis.
- Worked on ultrasound localization microscopy (ULM) data analysis applied to a glioblastoma (GBM) mouse model.
